# Ploutos 도메인 모델 초안

근거: [주요 기능](https://github.com/SWPY6/fe/wiki/%EC%A3%BC%EC%9A%94-%EA%B8%B0%EB%8A%A5), [기능정의서 v2](https://github.com/SWPY6/fe/wiki/%EA%B8%B0%EB%8A%A5%EC%A0%95%EC%9D%98%EC%84%9C)

## 서비스가 다루는 일

사용자는 국내·해외시장의 흐름을 살펴보고 산업에서 종목을 찾는다. 종목의 가격·거래량 변화와 같은 시기에 발표된 뉴스·공시를 함께 확인해 변동 맥락을 이해한다. 로그인한 사용자는 관심 산업과 종목별 가격 알림을 저장해 이후에도 추적한다.

## 시장 정보

| 개념           | 의미와 다른 개념과의 연결                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 시장 범위      | 국내 또는 해외를 선택하는 탐색 맥락. 선택한 범위에 따라 지표, 산업, 종목, 통화와 기준 시각이 정해진다. |
| 산업           | 선택한 시장에서 종목을 묶는 분류. 산업 탐색과 종목 필터가 같은 분류를 사용한다.                        |
| 종목           | 이름과 코드·티커로 찾는 개별 주식. 시장 범위에 속하며 산업 분류에 연결될 수 있다.                      |
| 종목 가격 기록 | 한 종목의 특정 시각 또는 거래일에 관찰된 가격·거래량. 시간에 따른 변화를 보여준다.                     |
| 시장 지표      | 지수·환율·유가처럼 시장 상황을 관찰하는 대상. 각 관측값에는 단위와 기준 시각이 따른다.                 |
| 관련 자료      | 출처, 발표 시각, 원문을 가진 뉴스 또는 공시. 종목이나 산업에 연결된다.                                 |

산업 동향은 산업과 소속 종목의 가격 기록에서 얻은 결과다. 주요 변동 종목은 종목과 가격 기록에 탐색 조건을 적용한 결과다. 시장 요약과 종목 상세는 해당 범위나 종목에 관한 지표·기록·자료를 함께 보여주는 구성이다.

변동 맥락은 관찰된 가격·거래량 변화와 관련 자료를 함께 제시한다. 관련 자료의 존재만으로 가격 변동의 원인을 단정하지 않는다.

## 사용자 추적

| 개념           | 소유자와 상태                                                                            |
| -------------- | ---------------------------------------------------------------------------------------- |
| 사용자 계정    | 저장한 관심 산업과 가격 알림의 소유자.                                                   |
| 관심 산업 고정 | 사용자와 산업의 연결. 고정한 산업의 순서가 계정에 저장된다.                              |
| 가격 알림 설정 | 사용자와 종목의 연결. 목표 가격, 이상·이하 조건, 활성 상태를 가진다.                     |
| 도착한 알림    | 가격 알림 조건에 따라 사용자에게 전달된 결과. 설정한 조건과 전달된 결과를 각각 확인한다. |

## 개념 간 관계

| 관계                                | 규칙                                                                                                                  |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 시장 범위 → 산업·종목·시장 지표     | 선택한 국내·해외시장에 속한 대상을 조회한다. 시장을 바꾸면 조회 대상과 통화·기준 시각도 함께 바뀐다.                  |
| 산업 → 종목                         | 분류된 종목은 하나의 산업에 속한다. 기타·미분류 종목은 산업 분류 없이 전체 종목 조회에 포함한다.                      |
| 종목 → 종목 가격 기록               | 한 종목에 시각 또는 거래일별 기록이 쌓인다. 현재가와 등락은 표시된 기준 시각 및 직전 정규장 종가를 기준으로 해석한다. |
| 시장 지표 → 관측값                  | 지수·환율·유가의 관측값은 각각 단위와 기준 시각을 가진다.                                                             |
| 관련 자료 → 산업·종목               | 뉴스·공시는 산업이나 종목에 연결될 수 있다. 연결은 가격 변동의 원인이라는 뜻이 아니다.                                |
| 사용자 계정 → 관심 산업 고정        | 사용자별로 최대 3개를 저장하고 고정 순서를 유지한다.                                                                  |
| 사용자 계정 → 가격 알림 설정 → 종목 | 목표 가격은 0보다 크고 조건은 이상·이하다. 종목별 설정은 독립적으로 변경한다.                                         |
| 가격 알림 설정 → 도착한 알림        | 설정은 앞으로 알릴 조건이고, 도착한 알림은 조건에 따라 전달된 결과다.                                                 |

## 확인된 제품 규칙

- 시장·산업·종목 정보는 비회원도 조회한다. 관심 산업과 가격 알림의 저장은 로그인 후 사용한다.
- 시장 범위를 바꾸면 지표·산업·종목 데이터와 통화·기준 시각이 함께 바뀐다.
- 현재가는 데이터 제공처에서 최근 수신한 가격이다. 통화·가격 기준 시각·실시간 또는 지연 여부와 함께 다루며, 등락률은 직전 정규장 종가를 기준으로 계산한다.
- 산업 평균 등락률은 대상 종목의 일별 등락률 단순평균이다. 결측·거래정지·미매핑 종목은 산정에서 제외한다.
- 거래량 배수는 당일 누적 거래량을 직전 20거래일 평균 거래량으로 나눈 값이다. 20거래일 미만 종목은 배수를 계산하지 않고 거래량 급증 순위에서 제외한다.
- 사용자는 관심 산업을 최대 3개까지 고정한다. 로그인 사용자의 고정 상태와 순서는 재접속 후에도 유지된다.
- 가격 알림은 목표 가격 이상 또는 이하 도달 조건으로 설정한다. 목표 가격은 0보다 커야 한다. 사용자는 설정을 켜고 끄거나 수정·삭제할 수 있다.
- 종목별 가격 알림 설정은 독립적으로 변경된다.
- 뉴스·공시의 출처, 발표 시각, 원문을 확인할 수 있다. 관련 자료를 가격 변동의 원인으로 단정하지 않는다.

## 위키 문서 차이에 대한 프론트 적용 기준

- 기타·미분류 종목은 전체 종목 조회에 포함한다. 9개 산업 카드와 산업 평균 산정에서는 제외한다.
- 관심 종목 저장은 별도 기능으로 다루지 않는다. 저장 기능은 기능정의서에 명시된 관심 산업 고정과 종목별 가격 알림으로 한정한다.
