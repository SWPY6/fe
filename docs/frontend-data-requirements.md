# 화면 데이터 요구

[기능정의서 v2](./wiki-feature-spec.md)를 화면에서 사용할 데이터 기준으로 정리한다. 아래 이름은 프론트의 UI 모델을 설명하기 위한 것으로, 서버의 URL이나 응답 필드를 뜻하지 않는다.

## 공통 데이터

| 데이터         | 필요한 값                                                                             |
| -------------- | ------------------------------------------------------------------------------------- |
| 시장           | 국내·해외 구분, 해당 시장의 시간대                                                    |
| 종목 식별 정보 | 화면 이동과 저장에 사용할 식별값, 시장, 종목명, 코드·티커                             |
| 산업 식별 정보 | 산업 식별값과 표시명. 산업이 없는 종목도 목록에 표시할 수 있어야 한다.                |
| 시세           | 수치, 통화·단위, 기준 시각, 실시간·지연 여부. 제공되지 않는 수치는 결측으로 유지한다. |
| 관련 자료      | 자료 식별값, 뉴스·공시 구분, 제목, 출처, 발표 시각, 원문 URL, 화면에 필요한 경우 요약 |

## 주요 변동 종목

- **조회 조건:** 시장, 전체·상승 TOP·하락 TOP·거래량 급증, 검색어, 산업, 투자 유의 종목 제외 여부, 정렬 항목·방향, 페이지.
- **목록 결과:** 조건에 맞는 전체 건수, 현재 페이지, 페이지당 100건, 데이터 기준 시각, 현재 페이지의 종목 행. TOP·급증 목록은 최대 100건, 페이지 이동은 최대 5페이지다.
- **종목 행:** 순위, 종목 식별 정보, 산업 식별 정보, 현재가·통화, 등락률, 거래량, 20거래일 평균 대비 거래량 배수, 시가총액, 거래대금, 투자 유의 상태, 변동 배경.
- **필터 데이터:** 선택 가능한 산업의 식별값과 표시명. 전체 종목 결과에는 기타·미분류 종목도 포함한다.
- **결과의 의미:** 순위와 전체 건수는 현재 페이지가 아닌 전체 조회 결과를 기준으로 한다. 거래량 급증 결과에는 2배 이상인 종목만 포함하며, 평균 계산에 필요한 20거래일이 없는 종목은 제외한다. 제공되지 않는 행의 수치는 `정보 없음`으로 표시할 수 있게 결측으로 남긴다.

## 산업별 동향

- **입력:** 시장과 전체·상승·하락 탭. 시장 요약에서 들어왔다면 선택한 산업도 받는다.
- **산업 목록:** 해당 시장의 9개 산업 각각에 대해 식별값, 이름, 평균 등락률의 반올림 전 수치, 순위, 거래대금 변화율, 주요 종목 목록, 데이터 기준 시각.
- **주요 종목:** 종목 식별 정보, 현재가·통화, 등락률.
- **사용자 데이터:** 고정한 산업의 식별값과 순서. 화면은 `0/3` 표시와 고정 우선 정렬에 이를 사용한다.
- **화면에서 처리할 범위:** 9개 산업을 모두 받은 뒤 탭 필터와 고정 우선 정렬을 적용한다. 평균 등락률과 거래대금 변화율의 원자료는 화면에서 소속 종목 몇 개로 재계산하지 않는다.

## 시장 요약

- **오늘의 산업 흐름:** 9개 산업의 식별값, 이름, 평균 등락률, 순위, 소속 종목 수, 기준 시각. 관심 산업의 고정 여부는 사용자 데이터와 연결한다.
- **시장 지표:** 지수·환율·유가 각각의 식별값, 표시명, 현재값·단위, 등락률, 직전 거래일 종가, 기준 시각. 선택한 지표의 차트에는 거래일별 종가와 시가·고가·저가·종가가 필요하다.
- **핵심 소식:** 상승·하락 산업 각각의 식별 정보, 평균 등락률·순위, 상승·하락 종목 수, 거래대금 변화율, 연결된 뉴스·공시 목록. 관련 자료가 없으면 자료 영역을 비울 수 있어야 한다.
- **변동 종목 미리보기:** 상위 4개 종목의 식별 정보, 현재가·통화, 등락률, 거래량, 거래량 배수, 시가총액, 거래대금.
- **화면 상태:** 산업 카드의 현재 위치·자동 순환 상태, 선택 지표·차트 기간·모양·확대 범위는 화면의 조작 상태다.

## 종목 상세

- **기본 정보와 시세:** 종목 식별 정보, 산업, 현재가·통화, 직전 거래일 종가 대비 등락률, 가격 기준 시각, 실시간·지연 여부.
- **주요 지표:** 전일 종가, 시가·고가·저가, 거래량, 20거래일 평균 대비 거래량 배수, 시가총액, 거래대금.
- **차트:** 선택 기간의 거래일별 날짜, 시가·고가·저가·종가와 거래량. 거래량 평균선에는 표시 기간의 최신 시점 기준 직전 20거래일 평균값이 필요하다. 평균을 계산할 수 없으면 결측으로 둔다. 라인·캔들은 같은 가격 데이터를 사용한다.
- **변동 배경:** 요약 문장과 근거로 연결된 관련 자료의 식별값. 확인된 배경이나 자료가 없을 때도 표현 가능해야 한다.
- **뉴스·공시:** 각각의 자료 목록과 건수. 자료에는 제목, 출처, 발표 시각, 요약, 원문 URL이 필요하다.
- **가격 알림:** 이 종목에 저장된 알림의 식별값, 목표 가격·통화, 이상·이하 조건, 켜짐·꺼짐 상태. 로그인 여부도 알림 설정 동작에 필요하다.

## 공통 기능 데이터

- **통합 검색:** 검색어에 맞는 종목 식별 정보 목록. 선택한 종목의 시장을 상세 이동에 함께 사용한다.
- **계정과 저장:** 로그인 상태, 고정 산업의 순서, 종목별 가격 알림 목록. 저장된 항목은 재접속 뒤에도 같은 상태로 표시한다.
- **도착한 알림:** 알림 식별값, 해당 종목, 발송 시각, 목표 가격·조건. 알림이 없을 때는 빈 상태를 표시한다.

## 데이터 경계

산업 평균 등락률·거래대금 변화율과 종목 목록의 전체 건수·순위·TOP·급증 결과는 화면에 보이는 일부 행만으로 만들 수 없다. 이 값들은 완전한 시장 데이터를 기준으로 제공받는다. 화면은 받은 9개 산업의 탭 필터·정렬과 차트 표시 범위 같은 조작을 처리한다.

다음 단계에서 이 데이터 묶음을 조회·저장 동작의 입력과 출력으로 확정한다. 그 뒤 HTTP 요청과 개발용 응답을 연결한다.

기능정의서의 `RQ-0701`은 기타·미분류 종목을 포함하고 `RQ-1111`은 모든 종목을 9개 산업으로 분류한다. 산업이 없는 종목의 표시값과 산업 필터에서의 취급은 결정이 필요하다.
