# 도메인 문서

도메인 문서는 GitHub 작업 항목에 연결하는 보조 근거다. 여러 Issue에 영향을 주는 공통 용어와
결정을 보존하지만, 현재 작업 의도의 기준인 Issue를 대신하지 않는다.

## 확인 절차

공통 도메인 용어나 기존 설계 결정에 의존하는 작업을 시작하기 전에 다음 문서를 읽는다.

- 저장소 루트의 `CONTEXT.md` 또는 루트 `CONTEXT-MAP.md`가 연결하는 관련 도메인 문서
- 변경 영역에 영향을 주는 `docs/adr/` 아래의 ADR

해당 파일이 없으면 그대로 작업을 진행한다. 여러 작업에서 다시 사용할 용어나 중요한 결정이
생겼을 때만 `domain-modeling`을 통해 문서를 만든다.

관련 `CONTEXT.md`에 정의된 용어를 사용한다. 필요한 개념이 없다면 현재 작업에서만 쓰는 표현인지
공유 도메인에 실제로 빠진 개념인지 구분한 뒤 추가한다.

기존 ADR과 충돌하는 내용을 발견하면 알린다. 기존 기록을 덮어쓰지 말고, 이전 결정을 유지한
상태에서 대체하거나 폐기한 새 결정을 기록한다.

## 문서 위치

기본적으로 하나의 도메인 영역을 사용하는 저장소로 관리한다.

- 공통 용어집: `CONTEXT.md`
- 설계 결정: `docs/adr/`

저장소에 실제로 여러 도메인 영역이 생기고 문서를 나누는 편이 찾기 쉬울 때만
`CONTEXT-MAP.md`와 영역별 문서를 추가한다.
