# 프론트 구현 계획

기능 범위와 수용 기준은 [기능정의서 v2](./wiki-feature-spec.md)를 따른다. 대상은 시장 요약, 산업별 동향, 주요 변동 종목, 종목 상세와 공통 검색·계정·알림이다.

먼저 [화면 데이터 요구](./frontend-data-requirements.md)에 정리한 표시값·조회 조건·결측 상태를 확정한다. 그 결과로 조회·저장 동작의 입력과 출력을 정한 뒤 컴포넌트 구조와 HTTP 요청을 설계한다.

## 데이터 흐름

```text
HTTP 응답 → DTO 변환 → UI 모델 → React 컴포넌트
```

컴포넌트는 기능에 필요한 UI 모델을 받는다. 요청 모듈이 DTO를 UI 모델로 변환한다. React Query가 조회 결과를 보관한다. 개발 환경에서는 MSW handler가 HTTP 요청에 응답한다. 실제 API가 제공되면 요청 모듈과 handler를 계약에 맞춰 갱신한다.

값이 없으면 UI 모델에도 결측 상태를 남긴다. 산업 평균·종목 순위·거래량 급증 여부·전체 결과 수는 전체 시장 데이터를 기준으로 받은 값을 사용한다.

## 상태와 조회 범위

| 상태                                                         | 관리 위치                                         |
| ------------------------------------------------------------ | ------------------------------------------------- |
| 선택 시장, 종목 목록의 검색·필터·정렬·페이지                 | URL. 화면 이동과 새로고침 후에도 조건을 복원한다. |
| 시장·산업·종목·자료·사용자 저장 정보                         | React Query.                                      |
| 캐러셀 위치·재생, 차트 hover·확대, 대화상자, 저장 전 폼 입력 | 해당 화면의 React state.                          |

각 화면은 조회 중·조회 실패·결과 없음 상태를 구분해 안내하고, 실패한 조회를 다시 시도할 수 있게 한다. 상태를 어느 범위에 표시할지와 React 구현 방식은 화면의 데이터 의존 관계를 설계할 때 정한다.

## 구현 순서

| 순서 | 작업                                                                         | 완료 확인                                                                                                          |
| ---- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 1    | 주요 변동 종목: 목록 조회, 검색·산업·변동 조건, 정렬, 페이지, 투자 유의 제외 | `RQ-0701`~`RQ-0712`; 국내·해외, 빈 결과·오류·재시도, 모바일 표 확인                                                |
| 2    | 산업별 동향: 산업 카드, 탭·정렬, 산업 조건으로 종목 목록 이동                | `RQ-0601`~`RQ-0605`; 9개 산업, 필터 결과, 화면 이동 후 조건 확인                                                   |
| 3    | 종목 상세: 현재 정보, 차트, 뉴스·공시, 변동 맥락                             | `RQ-0801RQ-0803`~~,~~ `RQ-0901RQ-1008`; 기간·차트 형태·자료 원문, 결측·오류 확인                                   |
| 4    | 시장 요약: 산업 흐름, 시장 지표, 핵심 뉴스, 변동 종목 미리보기               | `RQ-0201`~`RQ-0501`; 자동 순환·차트 조작·자료 연결, 영역별 오류 확인                                               |
| 5    | 공통 검색·계정·저장 기능: 로그인·회원가입, 산업 고정, 가격 알림, 도착 알림   | `RQ-0101RQ-0111`~~,~~ `RQ-0606`~~,~~ `RQ-0804RQ-0806`, `RQ-1101`~`RQ-1108`; 비회원 정책과 재접속 후 저장 상태 확인 |
| 6    | 실제 API 연결: 기능별 DTO·변환 갱신, 실제 응답 검증                          | 같은 수용 기준을 실제 서버 데이터로 통과. MSW는 개발·테스트 환경에서 사용                                          |

각 화면은 데이터 요구를 바탕으로 조회·저장 동작의 입력과 출력을 정한 뒤 컴포넌트를 설계한다. 구현 단계에서는 정상·빈 결과·실패 응답을 HTTP 수준에서 검증하고 다음 화면으로 넘어간다.

## 명세 확인 항목

- `RQ-0205`와 `RQ-0605`는 산업 종목 보기의 이동 목적지가 다르다.
- `RQ-0701`은 미분류 종목을 포함하고 `RQ-1111`은 모든 종목을 9개 산업에 분류한다.
- `RQ-0404`가 서로 다른 두 기능에 중복 부여되어 있다.
